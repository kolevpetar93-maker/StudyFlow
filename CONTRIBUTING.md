# Kako sodelujemo

1. Izberemo nalogo in določimo odgovornega člana ter merila sprejema.
2. Za nalogo odpremo vejo, na primer `feature/predmeti`, `fix/casovnik` ali `docs/mockupi`.
3. Naredimo majhne, razumljive commite z opisom spremembe.
4. Pred pull requestom zaženemo `python scripts/check_project.py`; ob implementaciji dodamo tudi preverjanja aplikacije.
5. Pull request opiše rezultat in preverjanje. Drug član ga pregleda pred združitvijo v `main`, ko so člani vključeni.
6. Po združitvi zapremo Issue in posodobimo README oziroma dokumentacijo.

Dokler naloge še niso objavljene, uporabljamo oznake SF-01 do SF-12 iz [osnutkov](dokumentacija/07-zacetne-naloge.md). En član je nosilec posamezne naloge, drugi lahko pomaga ali pregleduje.

V repozitorij dodajamo samo projektne datoteke. Gesla, prijavni žetoni, osebni koledarji in dejansko zasebno učno gradivo ostanejo zunaj njega. V prototipih uporabljamo izmišljene podatke.
