# Dokumentacija StudyFlow

Dokumentacija prve oddaje pri RVIR. Vsebina je začetna zasnova in se bo dopolnjevala z razvojem.

| Dokument | Vsebina |
| --- | --- |
| [Projekt](01-projekt.md) | Namen, funkcije in ključni uporabniški scenariji |
| [Tehnična zasnova](02-tehnicna-zasnova.md) | Podatkovni model, arhitektura in tehnologije |
| [Načrt dela](03-nacrt-dela.md) | Faze, odgovornosti in osnutki nalog |
| [Razvoj in GitHub](04-razvoj-in-github.md) | Struktura kode, preverjanje, sodelovanje in objava |

| [Mockupi](mockupi/README.md) | Predlogi zaslonov in predvidena navigacija |

## Stanje prve oddaje

- [x] Opis projekta in glavnih funkcionalnosti.
- [x] Ključni uporabniški scenariji.
- [x] Začetni predlogi mockupov in navigacije.
- [x] Začetni podatkovni model in arhitektura.
- [x] README, projektna struktura in pripravljen CI workflow.
- [ ] Dodan DPU, ki ga pripravi ekipa.
- [ ] Objavljen javni GitHub repozitorij.
- [ ] Dodani člani ekipe in asistent; vabila sprejeta.
- [ ] Objavljeni začetni Issues z odgovornimi člani in prioritetami.
- [ ] Potrjena osebna razdelitev odgovornosti.
- [ ] Uspešno izvajanje CI na GitHubu za oddani commit.

Objavo repozitorija izvede uporabnik; vabila in Issues bomo uredili pozneje. Datume in povezave dodamo ob izvedbi. Lokalno preverjanje ne pomeni že uspešnega izvajanja GitHub Actions.
