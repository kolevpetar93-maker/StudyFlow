## Pred končno oddajo

- [ ] Ekipa pregleda zasnovo in potrdi obseg.
- [ ] V README dodamo povezavo do javnega repozitorija.
- [ ] Člani ekipe in asistent sprejmejo vabila.
- [ ] Issues so objavljeni, imajo odgovorne člane in prioritete.
- [ ] Potrdimo osebno razdelitev odgovornosti.
- [ ] GitHub Actions uspe za oddani commit; povezavo do izvajanja dodamo v dokumentacijo.
- [ ] Diagrami in mockupi se prikažejo na GitHubu, prototip pregledamo lokalno.

Lokalne datoteke ne nadomestijo objavljenih Issues, sprejetih vabil in uspešnega izvajanja CI na GitHubu. Te zahteve ostajajo odprte do izvedbe.
